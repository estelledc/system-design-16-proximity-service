# Security policy

This repository is a bounded learning lab, not a hosted discovery or location product.

Do not submit real bearer tokens, precise user locations, business records, internal data, or production connection strings. Use
only synthetic fixtures and disposable infrastructure. Report suspected secret or location exposure through a private GitHub
security advisory rather than a public issue.

The initial contract excludes production identity, anti-scraping, owner verification, moderation, legal/privacy compliance,
personalization, advertising, routing, live crowd data, replicated durability, backup/restore, and disaster recovery.
